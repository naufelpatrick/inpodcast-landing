# Imagem social do InPodcast

`inpodcast.jpg` reutiliza a capa oficial de 3000 × 3000 px existente no RSS, sem corte,
redesenho ou geração de arte. Não é uma imagem placeholder quebrada.

Origem verificada em 11/09/2026:
https://d3t3ozftmdmh3i.cloudfront.net/staging/podcast_uploaded_nologo/41991082/41991082-1759334070490-dda567f4321db.jpg

Para a versão final de compartilhamento, recomenda-se uma arte própria de **1200 × 630 px**,
com marca e texto dentro da área segura. Ela pode substituir este JPEG no mesmo caminho,
sem alterações de código. Plataformas podem recortar a capa quadrada atual ao exibir cards largos.
